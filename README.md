# Muse Shopping - Watch-to-Buy Social Commerce

International, AI-powered social commerce that turns short videos into shoppable stores.

**Problem:** Millions of viral creators on TikTok, Instagram, Facebook, X, YouTube have views but no direct platform to sell. They put personal Gmail/phone in bio (security risk). 【entity-Shopify¦canonical_name=Shopify】, 【entity-Amazon¦canonical_name=Amazon】, 【entity-Daraz¦canonical_name=Daraz】, 【entity-Meesho¦canonical_name=Meesho】 charge monthly/yearly fees upfront and are complex.

**Our Solution - 3 Core Rules:**
1. **ZERO Monthly/Yearly Fee:** No creator, store, or seller pays Muse Shopping monthly/yearly. Fee is taken ONLY after a buyer purchases a product. No Sale = No Fee.
2. **Verified Creator Onboarding:** User creates account by adding their viral TikTok/Insta/FB URL/image + personal ID verification -> Gets Verified Store for $0.
3. **Short-Form Only Stores:** Stores only allow Short Video, Feeds, Reels, Photos — because today's users are only interested in short content. No long videos.

**How it Works:**
- Creator uploads 15-30 sec Reel -> Meta SAM 3.1 auto-detects & segments products -> Interactive Buy Tags appear on video
- Buyer swipes feed like TikTok -> Taps tag -> Buys with local payment (eSewa, Khalti, Fonepay QR, COD in Nepal; UPI in India; Stripe globally)
- Auto Revenue Split: Brand Cost + Creator Profit + Small Platform Service Fee (only after sale)

**Meta Products Used:**
- SAM 3.1 + Muse Image: Auto product detection & tagging in video
- Muse Spark: Creator co-pilot for descriptions, scripts, hashtags
- Muse Code: Built swipe feed & checkout logic

**Tech:** Next.js, Tailwind, SAM 3.1 API, Meta Model API
